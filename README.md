# Подборка вин

Проверено на Python 3.14.3. Модель обучена в HW3_MMDA.ipynb; приложение её не переобучает.

Локальный запуск из папки репозитория:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Вкладки: оценка одного вина, метрики при выбранном пороге, пакетное предсказание CSV и коэффициенты модели. Общий порог задаётся в боковой панели, начальное значение взято из `config.json`. Пример входного CSV скачивается во вкладке пакетного предсказания.

`st.cache_resource` хранит один объект модели между перезапусками скрипта. `st.cache_data` кэширует таблицу и вероятности и выдаёт копии данных. Без декоратора `joblib.load` заново читал бы модель при каждом изменении виджета. При движении порога вероятности тестовой выборки берутся из кэша, меняются только метки и метрики. Пути строятся от `Path(__file__).parent`.

`model.joblib` содержит StandardScaler и LogisticRegression; `test.csv` — отложенные данные. Порог выбран по F1 на валидации, тест использован для финального отчёта. Наличие одинаковых строк без идентификаторов вин ограничивает независимость оценки. Коэффициенты описывают статистические связи, а не причины.
